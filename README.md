# CPA-RAG

This repository corresponds to the paper: **CPA-RAG: Covert Poisoning Attacks on Retrieval-Augmented Generation in Large Language Models**  

The source code is currently being organized and will be publicly released soon.

CPA-RAG studies poisoning risks in Retrieval-Augmented Generation (RAG) systems and develops a black-box framework for generating adversarial documents that influence retrieval and generation. Since the complete implementation contains attack optimization pipelines, poisoning generation modules, and operational components, directly releasing the full code may introduce potential misuse risks.

We are currently organizing the implementation and preparing a responsible artifact release. The future release will focus on reproducible academic evaluation, including sanitized evaluation scripts, analysis tools, defense-related components, and necessary experimental configurations, while excluding operational attack deployment components.

The code will be released after completing code organization and security review.
